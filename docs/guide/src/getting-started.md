# Getting started

This part gets RedSAT onto your machine and walks you through your first programs:

- **[Installation](getting-started/installation.md)**: build the `redsat` command from source.
- **[Your first program](getting-started/first-program.md)**: a small puzzle, line by line.
- **[Running programs](getting-started/running.md)**: the everyday commands, from running a
  program to seeing what the solver did.
- **[The REPL](getting-started/repl.md)**: build a program one statement at a time.
- **[Editor support](getting-started/editor.md)**: the VS Code extension, with highlighting,
  live errors and the inferred range of every unknown on hover.

Just curious? The [online playground](../) runs RedSAT programs in your browser, with nothing to
install.
